# ⚡ Claude Pro – Hype Edit

**Video:** [`claude-pro-hype.mp4`](claude-pro-hype.mp4) (1920×1080, 30 fps, 77 s)

Ein schneller Zickzack-Schnitt, komplett aus Code. Alles sitzt auf einem 150-BPM-Raster: Zooms, Kamera-Kippen, Blitze und Schnitte passieren auf dem Beat.

| Zeit | Abschnitt |
|---|---|
| 0:00 | Intro: Bildrauschen, „HALLO!“, „ICH BIN CLAUDE“, Countdown 3-2-1 |
| 0:06 | **Drop:** 8 Skills, die Kamera springt im Zickzack von Skill zu Skill |
| 0:19 | Speedrun: Ein Spiel wird gecodet, dann gespielt |
| 0:29 | Meme: „Ohne Claude“ vs. „Mit Claude“ mit Zickzack-Naht |
| 0:35 | Aufbau: Snare-Roll, Riser, „Warum Claude Pro?“ |
| 0:40 | **Drop 2:** 6 Gründe für Pro, abwechselnd von links und rechts |
| 0:59 | Preis: Trommelwirbel, „20 $“, Münzregen |
| 1:06 | Outro: „Worauf wartest du?“, Logo, claude.ai |

**Sound:** eigener Beat in f-Moll (Kick, Clap, Hi-Hat-Rolls, 808 mit Slides, Cowbell-Melodie, Saw-Stabs) plus Effekte (Hits, Booms, Whooshes, Scratch, Kasse, Münzen …). Die Voice-Drops sind Sätze aus der ElevenLabs-Aufnahme der langen Version (`../claude-pro-lang/sprecher/`).
