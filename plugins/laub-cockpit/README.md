# 🍂 Laub-Cockpit

Eine Mod für Claude Code: Herbst-Theme in Orange und Braun, ein Panel „Laub-Cockpit“ mit Ladebalken für laufende Projekte (bei 100 % kommt eine Meldung, dass das Projekt fertig ist) und Schnellknöpfe wie „Mehr Details“, „Neues Level“, „Bugs suchen“ und „Ideen“. Dazu die Slash-Befehle `/cockpit` und `/mehr-details`.

Panel und Theme erscheinen in der Claude-Desktop-App und in der Handy-App, nicht in der Web-Version im Browser.

## Installieren

```
/plugin install laub-cockpit --marketplace snake10-cool/Claude
```

Danach `y` zum Hinzufügen des Marketplace und mit Enter den Bereich wählen.

In der Desktop-App: Plus neben dem Eingabefeld → Plugins → Add marketplace mit `snake10-cool/Claude` → Add plugin.
